## About the Project
NaviGo is a smart transportation planner designed to help users explore travel options around Bengaluru.

## Planned Features
- Find nearby metro stations and BMTC bus stops.
- Explore routes and walking distances.
- Compare estimated travel costs and journey times.
- Consider weather conditions when recommending routes.
- Provide links to supported ride-booking services.

## Technology Stack
- Frontend: React
- Backend: Python with FastAPI
- Maps: OpenStreetMap and Leaflet
- Weather: Open-Meteo API
